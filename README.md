# Worst Route

The least efficient way to get anywhere in the US. Set a start, an end and some stops; get a
route that never repeats an intersection or a road and is as bad as the time budget allows.

The project scaffolding, the pipeline's first steps (download, filter, build) and the graph
package (a build's arrays and on-disk format, graph search, snapping) are built; the rest of the
pipeline and the engine are next. See `CLAUDE.md` for the map (where things live, commands,
conventions, the agent workflow), `docs/PLAN.md` for the design, and `docs/project_overview.md`
for status, roadmap and decisions.
