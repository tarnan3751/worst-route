# Worst Route

The least efficient way to get anywhere in the US. Set a start, an end and some stops; get a
route that never repeats an intersection or a road and is as bad as the time budget allows.

Nothing is built yet. See `CLAUDE.md` for the map (where things live, commands, conventions,
the agent workflow), `docs/PLAN.md` for the design, and `docs/project_overview.md` for status,
roadmap and decisions.
